# Agent Guidelines

Whenever you finish a task, produce a change manifest in the following format. That makes reviews faster because the user immediately knows whether they need to pay special attention to API changes or compatibility concerns.

```
Created
---------
...

Modified
---------
...

Deleted
---------
...

Public API Changes
------------------
...

Breaking Changes
----------------
None

Build Status
------------
✅ TypeScript
✅ Lint

Known Limitations
-----------------
None
```
