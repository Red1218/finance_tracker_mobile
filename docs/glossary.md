# Engineering Glossary

## Domain Model

A business representation used by the application.

## Database Row

The structure returned by Supabase.

## DTO

A data transfer object used as an input or output contract.

## View Model

A UI-focused representation of data.

## Repository

Responsible for persistence.

## Service

Responsible for business workflows.

## Aggregate

A business concept that owns a consistency boundary.

## Mapper

Converts between database rows and domain models.
