# Categories Testing

## Purpose

Defines the testing strategy for the Categories feature.

## Testing Levels

- Unit
- Integration
- React Query Hooks
- Components
- End-to-End

## Business Rules

Verify:

- Duplicate detection
- Archive behavior
- Delete restrictions
- System category protection

## Accessibility

Test keyboard navigation, focus management, and ARIA support.

## Test Data

Use builders for reusable test objects.

## Performance

Verify behavior with large datasets.

## Error Recovery

Ensure users can recover from validation and network failures.
