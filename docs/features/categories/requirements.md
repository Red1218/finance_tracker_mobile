# Categories Requirements

## Purpose

Categories organize financial transactions.

## Functional Requirements

- Create
- Edit
- Delete
- Archive
- Search
- Filter
- Sort

## Business Rules

- Categories belong to one user.
- Names should be unique within a type.
- Archived categories cannot be selected.
- Categories with transactions cannot be deleted.

## Non-Functional Requirements

- Responsive
- Accessible
- Secure
- Fully typed
- Tested

## User Stories

Document the primary user workflows for managing categories.
