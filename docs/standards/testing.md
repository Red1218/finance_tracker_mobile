# Testing Standards

## Principles

- Test for confidence, not coverage.
- Prefer many unit tests.
- Test business behavior.
- Keep tests independent and repeatable.

## Testing Pyramid

- Unit
- Integration
- End-to-End

## What to Test

- Business logic
- Validation
- Repositories
- Services
- Critical user journeys

## What Not to Test

- Framework internals
- Third-party libraries
- TypeScript itself
- Trivial code

## Test Naming

Use descriptive behavior-based names.

## Test Independence

Every test must be repeatable and isolated.
