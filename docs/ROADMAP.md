# Finance Tracker — Roadmap

This roadmap describes the high-level product phases for Finance Tracker.

It reflects priorities, not a fixed schedule. Phases may overlap as features mature.

For implementation status, refer to the codebase and active issues.

---

## Phase 1 — Foundation ✅

Core infrastructure and primary user workflows.

- Authentication (sign up, sign in, sign out)
- Categories (create, archive, system defaults)
- Spends (record, list, delete)
- Credit Cards (add, set default)
- Borrowings (record, list)
- Savings (record, list)
- Monthly budget limit

---

## Phase 2 — Interactions

Make recorded data actionable and editable.

- Edit and delete for all entity types (spends, savings, borrowings)
- Add spend form with full field support (category, payment method, date, note)
- Add saving and borrowing forms
- Month navigation (browse past months)
- Budget limit configuration UI

---

## Phase 3 — Dashboard & Insights

Give users a clear financial picture.

- Dashboard with spend summary and budget progress
- Spend breakdown by category (chart)
- Credit utilization per card
- Monthly savings summary
- Top categories and spending trends

---

## Phase 4 — Accounts & Budgets

Expand financial tracking depth.

- Multiple account types (savings accounts, wallets)
- Per-category budget limits
- Budget vs. actual comparison
- Carry-forward budget tracking
- Recurring transactions

---

## Phase 5 — Analytics & Reporting

Surface patterns and long-term trends.

- Month-over-month spend comparison
- Category trend analysis
- Net savings rate over time
- Export to CSV / PDF
- Spending forecasts

---

## Phase 6 — Platform & Operations

Production readiness and reliability.

- Push notifications (budget alerts, reminders)
- Offline support and local cache
- Data backup and restore
- App store submission (iOS + Android)
- EAS Build configuration

---

## Beyond This Roadmap

Features and improvements beyond Phase 6 are tracked in the project issue tracker.
This roadmap will be updated as the project evolves.
